# Метод замера метрик

Все метрики — управленческие оценки; точные значения — по данным Jira/Confluence.

## Поставка
- **Доля задач в спринте:** закрытые в спринте задачи / запланированные.
  Источник: Jira/Kaiten, отчёт по спринту.
- **Время реакции на изменение:** от запроса до оценки влияния.
  Источник: change request log.
- **Незапланированные межкомандные блокировки:** задачи, вставшие внезапно
  из-за невыявленной зависимости, за период. Плановые паузы (ожидание
  контракта по графику) НЕ входят. Источник: реестр зависимостей + Jira.
- **Переделки фронта из-за API:** задачи, возвращённые на доработку
  из-за изменения API. Источник: дефекты/переделки.

## PMO
- **Adoption Scrumban:** доля команд, реально использующих процесс
  (доска, демо, ретро). Источник: опрос + факт.
- **Эскалации приоритетов:** количество эскалаций за период.
  Источник: матрица эскалаций.

## Экономика
- **Точность бюджета портфеля:** факт / план × 100%.
  Источник: реестр портфеля.
- **Средняя стоимость спринта по строкам реестра:** простое среднее
  по строкам реестра; ориентир, а не фактическая стоимость спринта
  портфеля. Источник: реестр портфеля.

## Бизнес-эффект
- **Сокращение времени закупочной процедуры:** качественная оценка
  по интервью с заказчиком; при наличии данных — количественно.
- **Доля требований, принятых с первого раза:** принятые без переделки /
  общее количество. Источник: change request log.

## Качество
- **Критичные дефекты на ПИ:** количество критичных дефектов на
  предварительных испытаниях. Источник: QA-отчёт.
- **QA-гейт перед ПИ:** наличие процесса (да/нет) + результат.
