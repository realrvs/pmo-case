# Метрики: до/после

Все проценты — округлённые управленческие оценки по итогам ретроспектив
и выгрузок. Это не бухгалтерская точность: часть метрик качественные,
часть — приблизительные. Точные значения — по данным Jira/Confluence,
если они сохранились.

| Группа | Метрика | До | После | Метод замера |
|---|---|---|---|---|
| Поставка | Доля задач в спринте | ~60% | ~85% | Jira/Kaiten (отчёт по спринту) |
| | Время реакции на изменение | ~5 дней | 2 дня | Change request log |

## Пояснения
- «Незапланированные межкомандные блокировки» — это задачи, которые
  встали внезапно из-за невыявленной зависимости. Плановые паузы
  (например, фронт ждёт API-контракт по графику) сюда не входят
  (см. decision 006).
- «Средняя стоимость спринта по строкам реестра» — простое среднее
  по 4 строкам (12, 8, 6, 5); информативно только как ориентир,
  а не как фактическая стоимость спринта портфеля.
- Бизнес-метрики — качественные, требуют подтверждения заказчиком.
